# 七影蝶视觉修正（像素版）

本版针对游戏内反馈缩小了翅膀，统一像素画风格，重做了身体、触须和尾部物理。参考图是侧视图，因此每侧翅膀只保留一条长尾，整只蝴蝶共两条。

## 形态与动画

- 翼展参数从 8.2 缩小到 5.3 模型像素，翅面纵向尺寸从 15 缩小到 10，约缩小三分之一。对已有七影蝶同样生效，不需要重新召唤来改变保存的尺寸值。
- 翅膀为 256×256 透明 PNG、48 色像素调色板；身体、眼部、足和触须共用 64×64 像素材质。纹理采用最近邻采样。
- 身体仅保留圆润头部、略宽胸部、收细腹部和两根弯曲触须，去掉脚和凸出的眼部细节。身体使用现有浅白材质中平缓的小块区域，依靠形状与轻微色差表现层次。几何从 890 个四边形简化为 304 个。
- 身体通常向斜上方倾斜约 45°，随飞行轻微起伏。
- 每片翅膀相对身体水平面上抬约 75°（顶部双翅夹角约 30°）、下压约 45°。后缘及翼尖带小幅延迟，完整周期约 1.8 秒。下拍占周期 42%，上抬占 58%。下拍先用约半程时间缓慢走过前 24% 的角度行程，再明显加速，最后快速制动；上抬在短暂起步后基本匀速，最后约三分之一时间逐渐减速到顶部。分段速度曲线积分为角度，角度、速度和加速度连续，两个换向端点速度为零。
- 每侧长尾围绕一条十二段半刚性链展开。固定游戏刻内分四步计算重力、阻尼、弯曲恢复力和长度约束；在渲染帧之间插值。相邻段互相约束弯曲，靠近末端时弯曲恢复系数由 0.22 逐渐增至 0.82，速度保留系数由 0.48 降到 0.12。末端更多跟随上游平移，约束修正同步修正速度历史，避免把长度修正当成外力反复放大。每段与竖直方向夹角限制在约 31° 内，每刻局部转动不超过约 6°；保留根部小幅滞后。
- 窄带沿单一主链展开，避免各列独立变形造成尾尖扭成三角形。尾部没有地形碰撞或自碰撞模拟。

## 粉尘与 Sodium

Sodium 在项目中没有被声明为编译或运行依赖。本模组的实体动画、透明纹理和粒子使用 Minecraft/NeoForge 自带接口，不需要 Sodium，也不存在“只有编译依赖、运行时缺失”的问题。

此前粉尘不明显的直接原因之一，是所用的 8×8 粒子图仅有一个不透明像素，再叠加 0.006–0.012 的四边形半径与较弱透明度，实际亮点远小于预期。

本版换用有效覆盖面积更大的细点/星点，裁去多余透明边，半径调整为 0.010–0.016 方块。粒子带轻微闪烁，寿命 2–3 秒，从实际运动轨迹附近生成，并随年龄缓慢扩散、逐渐变淡。每粒随机选择淡紫色（#E1CCFF）、接近白色的淡蓝（#EAF7FF）或蓝色（#70ACFF）；最低方块光照为 11，保持微弱亮感，不向周围方块投射动态光。默认按 1/3 概率保留每个候选粒子，移动时平均每秒约 13.3 粒，停留时平均每秒约 3.3 粒，均为此前数量的三分之一。粒子仍遵从游戏的粒子数量选项，未绕过用户设置。

模型最低方块光照由 8 提高至上限 15，身体也使用此下限。可选动态光照资源亮度由 4 提高至 12，需兼容动态光模组支持。光照等级不是线性视觉亮度，因此不能保证画面亮度精确提高三倍；全身没有整片叠加的强发光层。

## 平滑飞行 AI（2026-09-08）

七影蝶使用独立的飞行控制器；其他蝴蝶保持原有行为。

- 默认巡航约 1.2 方块/秒，缓慢启动、减速，转弯时略微减速。
- 常规水平转向最大 2.4°/刻，转向速度也逐步变化；爬升/下降角度每刻最多改变 0.8°。目标切换与跨越 ±180° 朝向边界时都保持连续。
- 目标优先选在前方 6–10 方块，通常持续 5–8 秒或接近后提前换点；每次目标高度改变不超过 2.5 方块，逐渐靠近当地地表以上 3–7 方块。
- 身体朝向实际移动方向；客户端平滑追随同步后的位移，保留约 45° 仰身外形。
- 通过前方短距离体积检查避让方块、流体和活动实体；避让方向短暂保持，避免左右反复选择。靠近障碍时允许更快转向、减速或停住，解除障碍后恢复常规飞行。已经接触安全余量时允许向外脱离。
- 受伤击退暂时让出控制，水中保留原有上浮行为。使用 `NoAI:1b` 的测试实体维持原版静止控制方式。
- 保留出生区域约束；这是局部避障的连续漫游，不提供穿越任意封闭迷宫的全局路径保证。

## 设置与测试指令

客户端设置文件为 `config/ambientgogga-client.toml`：

```toml
[shichieichou]
minimumLight = 15
dustSize = 1.0
dustPerTick = 2
dustDensity = 0.3333333333333333
```

`dustDensity` 范围 0–1，控制飞行和悬停时的生成保留概率；默认 1/3。`dustSize` 范围 0.25–3，`dustPerTick` 范围 0–4（0 关闭拖尾）。如果已有配置被手动设为 0，需要恢复粒子数量。游戏粒子选项建议设为“全部”以便测试。

```mcfunction
/summon ambientgogga:shichieichou ~ ~2 ~ {PersistenceRequired:1b,ReleasedFromBottle:1b}
```

单独测试粒子注册及显示：

```mcfunction
/particle ambientgogga:shichieichou_trail ~ ~1.5 ~ 0.15 0.15 0.15 0.01 40 force
```

替换 JAR 后需要重启客户端，单纯重载资源不能更新 Java 动画代码。

## 本轮动画与模型验证（未启动游戏客户端）

- 本轮仅使用离线 Java 检查和可旋转 WebGL 预览。加速下拍配合移动、升降、转身的 1,200 刻压力检查中，末端相邻两段最大弯折约 0.883°，末端方向每刻最大变化约 6.317°（包含转身坐标变化）。
- 新增速度曲线检查：下拍前段行程比例、加速/制动、上抬匀速区、顶部缓停、换向静止及两段单调性。

## 构建与此前飞行验证

- `gradlew build --offline`：通过，包含 6,480 组静态姿态检查、动态尾部检查及 600 刻平滑飞行回归检查。
- 检查拍动角度、约 45° 仰角、周期、有效法线、主链定长和下垂约束；检查移动后的惯性、瞬移重置、不同渲染频率及重复阴影绘制不会改变模拟进度。
- `python tools/check_shichieichou_assets.py`：检查 256/64 尺寸、像素调色板、每侧只有一个尾部连通区域、粒子有效像素覆盖、身体浅白调色板，以及最终 JAR 的资源一致性和开发测试代码隔离。
- 此前飞行 AI 版本已在隔离的测试存档中启动 Minecraft，未加载 Sodium 或光影包。实际检查了上拍、下拍、白天、夜晚、移动和静止粉尘。2026-09-08 的测试增加了实际 AI 漫游、墙体与实体避让，逐服务端刻记录速度、朝向和碰撞；当前三色粉尘、浅白身体和收紧尾部均已在游戏内检查。
- 此前飞行 AI 版本的三只测试蝶各记录 884 个连续服务端刻（共 2,652 条）：最大速度约 1.2 方块/秒，常规转角约 2.4°/刻，身体朝向误差小于 0.003°。自由飞行无中途停顿；墙体与实体测试分别触发 96/46 刻避让，均无方块碰撞。原始轨迹与统计见 `build/visualcheck/flight-observations.csv`、`flight-summary.json`。
- 游戏截图位于 `build/visualcheck/run/screenshots/`；最终日志为 `build/visualcheck/launch-flight-final.log`。该测试只运行在 `build/visualcheck/run` 下的独立副本中。
- 具体光影包的 bloom 表现未验证；必要时降低 `minimumLight`。原版渲染无需额外软件。

## 预览与维护

离线可旋转预览：`build/preview/shichieichou.html`，使用实际 Java 翅面、身体和软链数据，照明为简化演示。

先构建，再运行 `python tools/build_shichieichou_preview.py` 即可重建预览。

核心实现：`ShichieichouAnimation`（尺寸/角度/仰角）、`ShichieichouPose`（每只实体的时序）、`ShichieichouTailSimulation`（软链）、`ShichieichouAnatomy`（身体与触须几何）。模型复用绘图缓冲，实体模拟保存在弱引用缓存中。`ShichieichouFlightMotion` 控制转向/升降/速度连续性，`ShichieichouMoveControl` 处理障碍与实际移动，`ShichieichouWanderGoal` 选择前方漫游目标。

纹理使用内置 imagegen 重绘并进行已授权的本地去底、缩放和像素调色板整理；当前提示词见 [贴图制作记录](shichieichou-art.md)。
