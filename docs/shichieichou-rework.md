# 七影蝶视觉修正（像素版）

本版针对游戏内反馈缩小了翅膀，统一像素画风格，重做了身体、触须和尾部物理。参考图是侧视图，因此每侧翅膀只保留一条长尾，整只蝴蝶共两条。

## 形态与动画

- 翼展参数从 8.2 缩小到 5.3 模型像素，翅面纵向尺寸从 15 缩小到 10，约缩小三分之一。对已有七影蝶同样生效，不需要重新召唤来改变保存的尺寸值。
- 翅膀为 256×256 透明 PNG、48 色像素调色板；身体、眼部、足和触须共用 64×64 像素材质。纹理采用最近邻采样。
- 身体由圆润的头胸部和逐渐收细的分节腹部组成；两根触须为弯曲的细管，有小型末端结构，并补上细足。
- 身体通常向斜上方倾斜约 45°，随飞行轻微起伏。
- 每片翅膀相对身体水平面上抬约 75°（顶部双翅夹角约 30°）、下压约 65°。后缘及翼尖带小幅延迟，完整周期约 1.8 秒。
- 每侧长尾围绕一条十二段软链展开。固定游戏刻内分四步计算重力、空气阻力、惯性和长度约束；在渲染帧之间插值。上翅下拍时尾部仍保持向下，移动和转向时会滞后回摆。
- 窄带沿单一主链展开，避免各列独立变形造成尾尖扭成三角形。尾部没有地形碰撞或自碰撞模拟。

## 粉尘与 Sodium

Sodium 在项目中没有被声明为编译或运行依赖。本模组的实体动画、透明纹理和粒子使用 Minecraft/NeoForge 自带接口，不需要 Sodium，也不存在“只有编译依赖、运行时缺失”的问题。

此前粉尘不明显的直接原因之一，是所用的 8×8 粒子图仅有一个不透明像素，再叠加 0.006–0.012 的四边形半径与较弱透明度，实际亮点远小于预期。

本版换用有效覆盖面积更大的细点/星点，裁去多余透明边，半径调整为 0.010–0.016 方块。粒子有可见的闪烁平台期，寿命 1.6–2.4 秒，按实际移动方向向后播撒并逐渐扩散。默认移动时每刻两粒，停留时每两刻一粒。粒子仍遵从游戏的粒子数量选项，未绕过用户设置。

模型最低方块光照仍为默认 8；身体的小面积细节使用略高的光照下限。全身没有整片叠加的强发光层，可选动态光照资源亮度为 4。

## 设置与测试指令

客户端设置文件为 `config/ambientgogga-client.toml`：

```toml
[shichieichou]
minimumLight = 8
dustSize = 1.0
dustPerTick = 2
```

`dustSize` 范围 0.25–3，`dustPerTick` 范围 0–4（0 关闭拖尾）。如果已有配置被手动设为 0，需要恢复粒子数量。游戏粒子选项建议设为“全部”以便测试。

```mcfunction
/summon ambientgogga:shichieichou ~ ~2 ~ {PersistenceRequired:1b,ReleasedFromBottle:1b}
```

单独测试粒子注册及显示：

```mcfunction
/particle ambientgogga:shichieichou_trail ~ ~1.5 ~ 0.15 0.15 0.15 0.01 40 force
```

替换 JAR 后需要重启客户端，单纯重载资源不能更新 Java 动画代码。

## 验证

- `gradlew build --offline`：通过，包含 6,480 组静态姿态检查及动态软链检查。
- 检查拍动角度、约 45° 仰角、周期、有效法线、主链定长和下垂约束；检查移动后的惯性、瞬移重置、不同渲染频率及重复阴影绘制不会改变模拟进度。
- `python tools/check_shichieichou_assets.py`：检查 256/64 尺寸、像素调色板、每侧只有一个尾部连通区域、粒子有效像素覆盖，以及最终 JAR 的资源一致性和开发测试代码隔离。
- 已在隔离的测试存档中启动 Minecraft，未加载 Sodium 或光影包。实际检查了上拍、下拍、白天、夜晚、移动和静止粉尘。最终一次检查统计到移动时 80 个存活拖尾粒子、静止时 22 个。
- 游戏截图位于 `build/visualcheck/run/screenshots/`；最终日志为 `build/visualcheck/launch-ribbon.log`。该测试只运行在 `build/visualcheck/run` 下的独立副本中。
- 具体光影包的 bloom 表现未验证；必要时降低 `minimumLight`。原版渲染无需额外软件。

## 预览与维护

离线可旋转预览：`build/preview/shichieichou.html`，使用实际 Java 翅面、身体和软链数据，照明为简化演示。

先构建，再运行 `python tools/build_shichieichou_preview.py` 即可重建预览。

核心实现：`ShichieichouAnimation`（尺寸/角度/仰角）、`ShichieichouPose`（每只实体的时序）、`ShichieichouTailSimulation`（软链）、`ShichieichouAnatomy`（身体与触须几何）。模型复用绘图缓冲，实体模拟保存在弱引用缓存中。

纹理使用内置 imagegen 重绘并进行已授权的本地去底、缩放和像素调色板整理；当前提示词见 [贴图制作记录](shichieichou-art.md)。
