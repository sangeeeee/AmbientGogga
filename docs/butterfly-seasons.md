# 蝴蝶生成季节

配置文件为游戏或服务器目录中的 `config/ambientgogga-server.toml`。这是服务端配置，普通蝴蝶的实体生成由逻辑服务端控制：单机使用本地配置，多人服务器使用服务器上的配置。

```toml
[butterflies]
spawnSeason = "NON_WINTER"
```

- `ALL_YEAR`：全年，默认选项。
- `NON_WINTER`：非冬季。安装节气模组后，立冬、小雪、大雪、冬至、小寒、大寒这六个节气不自然生成普通蝴蝶，其余十八个节气允许通过季节检查。

七影蝶拥有独立的生成流程，不读取这个季节限制。已有蝴蝶不会因为入冬而被移除，指令、刷怪蛋和瓶中释放也不受新增限制影响。群系、地面、亮度和天气等原有自然生成条件继续生效。

没有安装节气模组时，两种选项均沿用全年行为。安装后以游戏世界的节气日历为准；在非冬季模式下，日历尚未可用或返回无效节气时暂缓自然生成，避免错误放行。

节气 API 继续仅作为编译依赖，不随本模组分发。季节查询只发生在受限制的普通蝴蝶生成检查中，同一维度、同一游戏刻共享日历结果；没有新增每实体或每渲染帧的季节检查。

验证包含二十四节气、冬季边界、默认配置与两种取值的 TOML 往返、非法配置修复、默认配置示例，以及缺少节气 API 时兼容类加载。完整游戏内的自然生成未实测。旧版配置自动迁移方式见 [配置说明](configuration.md)。
